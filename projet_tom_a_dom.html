Tom à Dom

Plateforme Web de services à la personne

Aperçu du projet

Suivez ici le développement de cette application web, de la conception de la base de données à l'intégration finale.

Journal de bord du projet

1

Modélisation de la Base de Données

MLD initial : tables Utilisateurs, Prestations et Réservations.

La première étape a consisté à définir les entités nécessaires. Nous avons opté pour une base de données relationnelle MySQL. J'ai créé les tables pour gérer les clients (nom, email, adresse), les types de services proposés et les demandes d'intervention.

2

Développement de l'Espace Client

Formulaire d'inscription avec validation côté client et serveur.

Création de l'interface publique. Intégration du formulaire d'inscription en HTML/CSS et développement de la logique PHP pour insérer les nouvelles données client dans la table `utilisateurs` de la BDD.

3

Tableau de Bord Administrateur

Dashboard permettant la validation ou le refus des réservations.

Développement de la partie back-office sécurisée. L'administrateur peut visualiser, modifier ou supprimer les réservations clients. Une connexion à la base de données permet d'afficher l'état de chaque demande en temps réel.

4

Tests et Finalisation

Interface finale responsive de l'application.

Phase de test rigoureuse : vérification de la sécurité des formulaires, test des différents scénarios utilisateurs et ajustements finaux du responsive design pour s'assurer que le site est utilisable sur mobile.
